# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Only you and the maintainers can see the report until the maintainers publish an advisory.

Keep vulnerability details out of public issues, pull requests, and discussions.

## Supported versions

Only the latest release is supported. Security fixes land on the `main` branch and ship in the next release.
